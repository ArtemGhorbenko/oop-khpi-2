Висновок:
У цій лабораторній роботі було успішно застосовано механізм узагальнень (Generics) для створення типобезпечної та гнучкої моделі системи бронювання

Головні результати:
Типобезпека та перевикористання коду:** Розроблено узагальнений клас `BookingRecord<TClient, TResource>`, який дозволяє зв'язувати клієнта з будь-яким типом ресурсу. Це усунуло потребу в дублюванні коду для різних типів бронювань і дозволило уникнути небезпечного приведення типів
Обмеження типів:** Реалізовано узагальнений метод `findMaximum` із застосуванням верхньої межі `<T extends Comparable<T>>`. Це гарантує, що метод працюватиме виключно з тими об'єктами, які підтримують операцію порівняння, забезпечуючи надійність ще на етапі компіляції
Покращення API:** Продемонстровано, що використання Generics робить архітектуру програми більш надійною, оскільки всі помилки невідповідності типів виявляються під час компіляції коду, а не під час його виконання
