# oop-khpi-2
Роботи Горбенко Артема Групи КН-1024В

У ході лабораторної роботи було реалізовано чотирирівневу ієрархію класів (MedicalWorker $\rightarrow$ Doctor $\rightarrow$ Surgeon $\rightarrow$ CardiacSurgeon) із розгалуженням на рівні педіатрії (Pediatrician).Ключові результати:Практичне застосування ООП: Опрацьовано механізми успадкування стану через super(), перевизначення поведінки через @Override та обмеження розширення за допомогою final.Аналіз пам'яті: За допомогою інструменту JOL експериментально підтверджено, що об'єкт нащадка формується в пам'яті як єдиний блок розміром 32 байти, що містить поля всіх батьківських класів.Тестування: Коректність передачі стану та логіки методів на всіх рівнях ієрархії підтверджена успішним проходженням модульних тестів JUnit 5.Проєктування: Обґрунтовано доцільність узагальнення сутностей (на прикладі бібліотечної моделі LibraryItem) для зменшення дублювання коду та забезпечення поліморфної обробки даних.
