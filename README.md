 Висновок до ЛР №12 
У фінальній лабораторній роботі було успішно застосовано Stream API для декларативної обробки даних інтернет-магазину. Продемонстровано використання проміжних (`filter`, `map`, `flatMap`, `sorted`, `distinct`) та термінальних операцій (`collect`, `sum`, `max`). Зроблено порівняння імперативного та декларативного підходів, що довело переваги Stream API у плані читабельності, безпеки (використання `Optional`) та лаконічності коду.
