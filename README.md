 Висновок до ЛР №14
У цій роботі реалізовано базову багатопотоковість на прикладі інтернет-магазину. Продемонстровано створення потоків (через `Thread` та `Runnable`), паралельний запуск за допомогою `start()`, імітацію навантаження через `sleep()` та координацію завершення за допомогою методу `join()`.
