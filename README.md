У фінальній лабораторній роботі досліджено проблему спільного доступу до змінюваних даних. На прикладі системи бронювання готелю зімітовано стан перегонів (race condition) та втрату оновлень. Успішно застосовано ключове слово `synchronized` для захисту критичної секції, що гарантувало збереження цілісності даних. За допомогою вимірювання часу `System.nanoTime()` досліджено накладні витрати на синхронізацію.
