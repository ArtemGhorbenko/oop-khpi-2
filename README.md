## Висновок до ЛР №11 (Conclusion)
У даній лабораторній роботі було розроблено сервіс планувальника завдань з використанням Java Collections Framework. Продемонстровано цільове використання різних структур даних: `HashSet` для забезпечення унікальності команди, `LinkedList` у ролі `Queue` для диспетчеризації завдань (FIFO) та `ArrayList` для ведення реєстру активних процесів. Забезпечено типобезпеку (Generics) та коректну роботу методів обходу колекцій.
