# Звіт до лабораторної роботи №10

1. Варіант: 3.

2. Опис розробленого контейнера
Було розроблено узагальнений контейнер `BookingContainer<T>`, який забезпечує динамічне зберігання даних на базі масиву. Архітектура класу передбачає автоматичне розширення місткості при досягненні ліміту. Використання параметризації (Generics) гарантує типобезпеку та дозволяє зберігати об'єкти системи бронювання без необхідності приведення типів.

3. Імплементація ітератора
Для забезпечення сумісності контейнера зі стандартними синтаксичними конструкціями Java (цикл `for-each`), клас імплементує інтерфейс `Iterable<T>`. Навігація масивом інкапсульована у внутрішньому класі `BookingIterator`, який реалізує інтерфейс `Iterator<T>`. Такий підхід захищає внутрішню структуру даних від прямого втручання з боку клієнтського коду.

4. Висновок
Під час виконання лабораторної роботи було реалізовано власну структуру даних типу "динамічний масив". Практично застосовано патерн проєктування "Ітератор", що дозволило абстрагувати процес перебору елементів колекції від її внутрішньої реалізації. Модель системи бронювання успішно інтегрована з розробленим контейнером.
